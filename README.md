# 📱 Mobile Sales Dashboard — Power BI

An interactive **Mobile Sales Dashboard** built using **Microsoft Power BI** to analyze mobile phone sales performance, customer behavior, and sales trends.

## 📊 Dashboard Overview

The dashboard provides a visual analysis of mobile sales data and helps identify important business insights through interactive charts, KPIs, and filters.

### Key Metrics

* 💰 Total Sales
* 📦 Total Quantity Sold
* 🧾 Total Transactions
* 📱 Mobile Brand Performance
* 🌍 Sales by City/Region
* 📅 Monthly Sales Trends
* 💳 Payment Method Analysis
* ⭐ Customer Ratings

## 🔍 Key Features

* Interactive Power BI dashboard
* KPI cards for quick performance overview
* Sales analysis by mobile brand
* Monthly and daily sales trends
* Geographic sales analysis
* Payment method comparison
* Customer rating analysis
* Interactive slicers and filters
* Easy-to-understand visualizations

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query** — Data cleaning and transformation
* **DAX** — Measures and calculations
* **Data Visualization**
* **Excel/CSV Dataset**

## 📈 Dashboard Insights

The dashboard can be used to analyze:

* Which mobile brands generate the highest sales
* Sales performance over different time periods
* Which locations contribute the most sales
* Customer purchasing patterns
* Popular payment methods
* Relationship between customer ratings and sales
* Overall sales and quantity performance

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Refresh the dataset if required.
4. Use the slicers and interactive visuals to explore the dashboard.

## 🎯 Project Objective

The main objective of this project is to transform raw mobile sales data into an interactive dashboard that provides meaningful insights into **sales performance, customer behavior, product performance, and geographical trends**.
